N B G NANAYAKKARA & CO — WEBSITE
Accounting & Auditing Firm · Ethul Kotte, Sri Lanka
====================================================

WHAT'S INSIDE
-------------
index.html        Home page (hero with 3D art, trust strip, about,
                  services preview, animated counters, why-us, CTA)
services.html     Services page (6 detailed services, how-we-work steps)
contact.html      Contact page (contact cards, WhatsApp enquiry form,
                  Google map, office photo gallery)
css/style.css     Full stylesheet (dark theme, brand palette, 3D effects)
js/main.js        Lightweight vanilla JS (animated counters, 3D card tilt,
                  scroll reveal, mobile nav, WhatsApp form composer)
assets/images/    Logo set, favicon, office photos, generated 3D graphics

HOW TO USE
----------
1. Keep the folder structure as-is (index.html at the root).
2. To preview locally: double-click index.html, or run a local server
   (e.g. `python3 -m http.server`) inside this folder.
3. To publish: upload the whole folder to any static hosting
   (Netlify, Vercel, cPanel, GitHub Pages...). No build step needed.

EDITING TIPS
------------
- Phone numbers / address appear in the top bar, footer, contact cards
  and CTA bands of every page — search & replace if they ever change.
- The enquiry form opens WhatsApp (077 303 8540) with a pre-filled
  message. To use a different WhatsApp number, edit `94773038540`
  in js/main.js.
- Stats (32+ years, 100+ clients, 4.5 rating) are set via
  data-target attributes and as plain fallback text.
- The map on contact.html uses Google's keyless embed for the office
  address; replace the iframe src to change it.

NOTES
-----
- Fonts load from Google Fonts (Marcellus + Inter); the site degrades
  gracefully to system fonts offline.
- All facts shown (32 years, 100+ clients, 4.5 stars, phones, address)
  are as supplied by the firm.
